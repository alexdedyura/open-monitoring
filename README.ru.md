# Open Monitoring

Бесплатный мониторинг ПК для Windows с открытым исходным кодом — альтернатива
MSI Afterburner и FPS Monitor. Живая панель показаний, записываемые сеансы с
масштабируемыми графиками и оверлей поверх остальных окон для игр. Один
исполняемый файл, ставить рядом с ним нечего.

**[Скачать](https://github.com/alexdedyura/open-monitoring/releases/tag/latest)**
· **[Документация](https://alexdedyura.github.io/open-monitoring/)**

## Возможности

- **Живая панель показаний** — CPU (общая загрузка и по ядрам), RAM, файл
  подкачки, GPU, VRAM, дисковый ввод-вывод и сеть на потоковых графиках с
  окнами 1, 5, 15 и 30 минут. Тёмная и светлая темы, обе проверены на
  различимость при дальтонизме; интерфейс следует масштабу экрана Windows или
  фиксируется на 100–200%.
- **Видеокарты всех вендоров** — загрузка, VRAM, температура, горячая точка,
  потребление, частоты и вентилятор для NVIDIA, AMD и Intel, без установки
  фирменных утилит.
- **FPS игры, в которую вы играете** — текущий, средний, минимумы 1% и 0.1%,
  замеряет [Intel PresentMon](https://github.com/GameTechDev/PresentMon).
- **Частота, температура и потребление CPU** — реальная частота ускорения
  самого быстрого ядра, температура и потребление по пакету.
- **Накопители** — текущие скорости чтения и записи и свободное место по томам,
  а по каждому устройству — модель, шина, состояние, температура SMART,
  остаточный ресурс и наработка.
- **Процессы** — живая таблица всего, что запущено: CPU, память, ввод-вывод и
  число потоков по каждому процессу, с сортировкой, фильтром и группировкой по
  имени, чтобы тридцать процессов браузера читались одной строкой.
- **Сведения о системе** — сводка по оборудованию: CPU, GPU, модули памяти,
  системная плата, ОС и время работы, накопители.
- **Стресс-тест** — прогрев CPU, памяти, GPU и накопителя по отдельности или
  всего сразу, от минуты до часа или до остановки вручную. Нагрузка на CPU
  чередует FMA-инструкции AVX-512 и AVX2, AES-NI, инструкции SHA, длинную
  арифметику и работу с кэшем; память и VRAM заполняются, прогоняются и
  сверяются с записанным узором, так что неисправный модуль или неустойчивый
  разгон памяти проявляется числом несовпадений; накопитель измеряется без
  буферизации, последовательно и случайными запросами по 4 KB при глубине
  очереди 16. Скорость, пиковые температуры, частоты и потребление показываются
  по ходу прогона. Ни драйверов, ни сред выполнения ставить не нужно — работа с
  GPU идёт через OpenCL, который уже установлен вместе с драйвером экрана.
- **Запись** — сохранение всех метрик от 1 до 4 часов, затем просмотр
  масштабируемыми графиками (выделение мышью — увеличить, двойной клик —
  сбросить) или выгрузка всех графиков одним PNG.
- **Оверлей HUD** — компактный безрамочный оверлей в духе классического
  игрового OSD: разделы по оборудованию с построчным выбором, спарклайны FPS и
  времени кадра, регулируемая непрозрачность и закрепление в углу экрана.
  Работает поверх игр в окне и в полноэкранном оконном режиме; глобальные
  сочетания клавиш показывают и скрывают его (`Ctrl+Alt+H`) и сбрасывают
  средние значения для нового замера (`Ctrl+Alt+B`), не выходя из игры. Оверлей
  можно сделать прозрачным для мыши (`Ctrl+Alt+T`), чтобы случайные клики
  попадали в игру, а не в HUD. Все сочетания переназначаются в настройках, там
  же видно, если сочетание уже занято другим приложением.
- **Оповещения по порогам** — уведомление Windows и всплывающее сообщение в
  приложении, когда температура CPU или GPU, загрузка RAM или заполнение
  накопителя выходят за предел. Пороги настраиваются по каждому правилу;
  оповещение срабатывает один раз за событие и взводится заново только после
  того, как значение вернулось в норму, — так один жаркий день даёт одно
  уведомление, а не поток.
- **Встроенные обновления** — приложение раз в сутки проверяет релизы на GitHub
  (можно отключить) и обновляется в один клик со вкладки «О программе»: новый
  исполняемый файл скачивается и заменяет старый, без переустановки, настройки
  и записи остаются на месте.

## Загрузка

Каждый push в основную ветку собирается через GitHub Actions и публикуется в
скользящий релиз [**latest**](https://github.com/alexdedyura/open-monitoring/releases/tag/latest):

- **Установщик** (`open-monitoring-amd64-installer.exe`) — ярлыки в меню «Пуск»
  и на рабочем столе, деинсталлятор и необходимый драйвер PawnIO отдельным
  компонентом, выбранным по умолчанию.
- **Портативная версия** (`open-monitoring.exe`) — один файл без каких-либо
  требований; драйвер PawnIO предлагается установить при первом запуске.

Приложение полностью портативно в обоих случаях: настройки и записанные сеансы
лежат в скрытой папке `.open-monitoring` рядом с исполняемым файлом — ни в
реестр, ни в AppData ничего не пишется.

Windows 10/11, 64-разрядная. Приложение запрашивает права администратора при
запуске: счётчики SMART и захват кадров без них недоступны, так же как в MSI
Afterburner.

## Драйвер PawnIO

Температуру и потребление по пакету CPU можно прочитать только из нулевого
кольца, поэтому нужен драйвер режима ядра. Open Monitoring не ставит
собственный: он опирается на [PawnIO](https://pawnio.eu) — небольшой драйвер с
открытым исходным кодом, который устанавливает инсталлятор или который
приложение предлагает поставить в один клик при первом запуске (через
`winget`). Пока драйвера нет, приложение остаётся на экране установки.

Подробнее о причинах и о том, что делать, если winget недоступен, — в
[документации по PawnIO](https://alexdedyura.github.io/open-monitoring/pawnio).

## Сборка из исходников

Требуются Go 1.26+, Node.js 26+,
[Wails CLI](https://wails.io/docs/gettingstarted/installation) v2 и .NET 8 SDK
(для вспомогательной службы датчиков — конечным пользователям .NET не нужен).

```powershell
.\build.ps1
```

Результат — `build/bin/open-monitoring.exe`, около 50 МБ, без единого файла
рядом. Параметры описаны в
[руководстве по сборке](https://alexdedyura.github.io/open-monitoring/building),
а способы получения данных — в
[справочнике по метрикам](https://alexdedyura.github.io/open-monitoring/metrics).
