One click turns the window into a compact, frameless, always-on-top overlay
styled like a classic in-game OSD.

## What it shows

Titled sections per hardware, each with per-row toggles:

- **GPU** — load, VRAM, temperature, power, clocks.
- **CPU** — load, clock, temperature, power.
- **Memory** — RAM and page file.
- **Storage** — live read/write speeds.
- **Network** — throughput.
- **FPS** — current / average / 1% low / 0.1% low, with live FPS and
  frame-time **sparklines**.

## Keyboard shortcuts

Both are registered system-wide, so they work while a game has focus:

| Shortcut | Does |
|---|---|
| `Ctrl+Alt+H` | Show or hide the overlay |
| `Ctrl+Alt+B` | Restart the average and the 1% / 0.1% lows |

The reset is what you press at the start of a run worth measuring — a
benchmark scene, a new area — so the cumulative numbers describe that and not
the loading screen before it. The current frame rate and the graphs keep
running.

Both can be changed under **Settings → HUD overlay**: click a shortcut and press
the combination you want. Letters, digits and F1–F24 are accepted, with at least
one of Ctrl, Alt, Shift or Win; `Esc` cancels the capture. The new combination is
claimed the moment the settings are saved — no restart.

Windows gives a combination to whichever application registers it first and will
not say which one that was, so a perfectly valid shortcut can simply be dead. If
that happens the field says **held by another application** and you can pick
another — without it, a shortcut that never fires is indistinguishable from a
broken feature.

A shortcut with no modifier at all is still possible by hand-editing
`%APPDATA%\OpenMonitoring\config.json` (`hud.hotkeyToggle`, `hud.hotkeyReset`),
but the capture field will not produce one: a bare `H` is claimed globally too,
and would stop the letter reaching any other application, the game included.

## Positioning and appearance

- **Screen anchoring** — free drag anywhere, or snap to any corner of the
  screen.
- **Opacity control** — from fully opaque to nearly transparent.
- Every row can be toggled individually, so the HUD shows exactly what you
  care about and nothing else.

## Game compatibility

The HUD works over **windowed** and **borderless-fullscreen** games — it
re-asserts its always-on-top status continuously, so games that steal the
topmost slot do not push it behind.

**Exclusive fullscreen** bypasses any desktop overlay: the frame never passes
through the desktop compositor, so no window can draw over it without a D3D
hook. The app explains this before switching. Most modern games offer a
borderless-fullscreen mode, which behaves identically for gameplay and works
with the HUD.
